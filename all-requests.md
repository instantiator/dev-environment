# All requests

Follow read the documents referenced here as needed.

## Working style

Preparing a plan is a collaborative process. Present options to the user, discuss merits and drawbacks before committing to libraries, approaches, data structures, or key business logic.

## Code integrity

Determine if you have been asked to make a change to the code. If you have not, be careful not to - even when exploring possible outcomes. If you need to, and not explicitly permitted, ask for permission to make changes.

## Simplicity

Less is more. Aim for concise, readable code, and simple interfaces.
