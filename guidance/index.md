# Guidance

Read only what matches the task at hand — one doc at a time.

| Directory | When to look there |
|-|-|
| [process/](process/index.md) | The development process - what to do before, during, and after coding. Pick the file matching where you are in a task. |
| [standards/](standards/index.md) | Cross-language standards that apply to all code. Pick the file matching your current activity. |
| [languages/](languages/index.md) | Language-specific standards. Pick the file for the language you are working in. |
| [frameworks/](frameworks/index.md) | Framework-specific standards. Pick the file for the framework you are working in. |
| [infra/](infra/index.md) | Infrastructure-as-code standards and verification. Pick the file for the platform or tool in use. |
| [ci/](ci/index.md) | Continuous integration standards per platform. Pick the file for the CI system in use. |

For every coding task: [process/before-coding](process/before-coding.md) first, [standards/common](standards/common.md) always, [process/after-coding](process/after-coding.md) when done.

For multi-step tasks (setup, review, deploy, audit): check [../skills/index.md](../skills/index.md) for a matching skill.
